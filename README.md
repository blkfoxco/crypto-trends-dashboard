# Bitcoin vs BTCUSDT Search Interest + Price Dashboard

**Live dashboard →** https://crypto-trends-dashboard.vercel.app

An interactive chart overlaying Google Trends search interest for **Bitcoin** and **BTCUSDT** against the BTCUSDT price over the last 5 years. Updated weekly every Monday at 01:00 GMT+7.

## What It Shows

- **Google Trends** — relative search interest for the terms "Bitcoin" and "BTCUSDT" over the past 5 years. Each term is queried on its own and indexed to its own peak week (100)
- **BTCUSDT price** — weekly closing price from Binance, plotted on a linear USD scale on the right axis

The chart helps visualise the relationship between public search interest and Bitcoin price cycles — useful as a directional signal for market sentiment.

## How It Works

- Data is fetched via [pytrends](https://github.com/GeneralMills/pytrends) (Google Trends) and the Binance public API
- Google Trends returns relative scores only. Each term is fetched in its own query, so its peak week reads 100; the chart compares shapes, not levels. BTCUSDT is searched far less than Bitcoin (1–10 against Bitcoin's 100 for most weeks, with a spike to 100 in August 2025)
- The dashboard is a single static HTML file generated by a Python script and deployed to Vercel
- A cron job regenerates and redeploys the file every Monday morning

## Stack

- **Python** — data fetching and chart generation (`trends.py`)
- **Plotly** — interactive charting (embedded in HTML)
- **Vercel** — static hosting and deployment

## Files

| File | Description |
|---|---|
| `index.html` | Generated dashboard (do not edit manually) |
| `trends_html.py` | Data fetch + interactive HTML chart generation |

## Running Locally

```bash
pip install -r requirements.txt
python trends_html.py
# Opens crypto_trends_dashboard.html in your browser
```

## Caveats

Google Trends represents *relative* search popularity, not absolute volume, and per-term indexing removes level information by design. Use as a directional signal, not a precise metric.
